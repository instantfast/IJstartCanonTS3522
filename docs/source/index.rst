IJ.start.Canon TS3522: Printer Setup and Installation Guide
==========================================================

Setting up a Canon PIXMA TS3522 involves preparing the printer, installing its ink cartridges, loading paper, and connecting it to your computer or phone. You can choose wireless printing or a USB connection according to your needs.

If you searched for IJ.start.Canon TS3522, this independent guide explains the setup process and common installation checks. It is not affiliated with Canon.

Before You Start
----------------

Place the printer on a flat, stable surface with enough room to open its covers and extend the paper output tray.

Have these items ready:

* The printer and its power cord.
* Compatible ink cartridges.
* Plain paper.
* Your computer or mobile device.
* Your WiFi network name and password.
* A compatible USB data cable if choosing a wired connection.

Remove the packaging and protective materials identified in the printer's setup instructions. Check inside accessible areas for shipping tape without forcing any moving parts.

Prepare the Canon PIXMA TS3522
------------------------------

Connect the Power
~~~~~~~~~~~~~~~~~

Connect the power cord securely and switch on the printer.

Wait for the printer to finish its initial startup. If an error appears, identify it before continuing with installation.

Install the Ink Cartridges
~~~~~~~~~~~~~~~~~~~~~~~~~~

Open the cartridge access area as described in the printer's instructions. Allow the cartridge holder to stop moving before touching it.

Remove the required protective tape from each cartridge. Avoid touching the electrical contacts and ink nozzles.

Place each cartridge in its correct position and secure it. Close the cover and allow the printer to complete its preparation.

Load Plain Paper
~~~~~~~~~~~~~~~~

Load a small stack of plain paper in the rear tray and adjust the paper guide without bending the sheets.

Extend the output tray. Match the paper size setting to the paper you loaded.

Complete any alignment process requested during setup.

Choose Wireless or USB Installation
-----------------------------------

Canon TS3522 wireless setup connects the printer to your router so compatible devices on the local network can print.

USB installation connects the printer directly to one computer. It is useful when you do not want to configure wireless printing.

Choose one method for the initial installation. You can configure another connection later if needed.

Canon TS3522 WiFi Setup
----------------------

Prepare Your Wireless Network
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The PIXMA TS3522 uses a 2.4 GHz wireless connection. Make sure your router provides a compatible 2.4 GHz network.

Your computer or phone can use another wireless band if both devices remain on the same local network and the router allows communication between them.

Avoid a guest network that isolates connected devices.

Start the Setup Process
~~~~~~~~~~~~~~~~~~~~~~~

Use a compatible Canon setup application or installation package for the TS3522 and your operating system.

Follow its instructions to place the printer into wireless connection mode. Button sequences and indicator patterns should be followed exactly as described for this model.

Choose your home network and enter its password when prompted.

Confirm the Connection
~~~~~~~~~~~~~~~~~~~~~~

Wait for the setup application to confirm that the printer has joined the network.

Complete the remaining installation steps, then print a small document. A successful test confirms communication from that device.

Install Canon TS3522 on Windows
-------------------------------

Prepare the printer and establish its USB or wireless connection according to the installation prompts.

On Windows 11, open Settings, select Bluetooth & devices, and choose Printers & scanners.

On Windows 10, open Settings, select Devices, and choose Printers & scanners.

Choose the option to add a printer. Select the TS3522 when it appears and complete the prompts.

Canon TS3522 Driver Installation
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

If additional software is needed, choose a trusted installation package intended for the PIXMA TS3522 and your Windows version.

Follow the installer's instructions about when to connect a USB cable. Avoid installing a driver for a different model.

After installation, select the correct printer entry in your application's print dialog.

Print a Test Document
~~~~~~~~~~~~~~~~~~~~

Open a short document and print one page.

Check that the paper size, orientation, and selected printer are correct before sending a larger job.

Connect Canon TS3522 to a Mac
-----------------------------

Join the printer to your wireless network or connect it through USB.

Open the Mac's printer settings and choose the option to add a printer. Select the TS3522 from the available devices.

Use AirPrint when it is available for your configuration. Check current model compatibility before installing additional software.

Finish adding the printer and print a short document.

Canon TS3522 Setup on a Phone
-----------------------------

Use a compatible mobile printing application or available built-in printing feature.

During initial wireless setup, the application may ask for permissions needed to discover and configure the printer. Review those prompts and allow the access required for the task.

After setup, confirm that your phone is connected to the same local network as the printer.

Open a document or photograph, select the TS3522, and review the paper settings before printing.

Install Canon TS3522 Without a CD
---------------------------------

A CD is not always necessary for Canon PIXMA TS3522 setup.

A computer may install a suitable printing driver automatically, while compatible devices may use a built-in printing method.

If you need an installation package, verify the model, operating system, and publisher before running it. Avoid unrelated driver updater tools.

Using a USB Connection
----------------------

Use a compatible USB data cable and connect the printer when instructed by the installer.

If the computer does not detect it, check both cable connections and try another USB port.

Connect directly to the computer while testing rather than through a hub or docking station.

Select the USB printer entry when printing. An old wireless entry may remain unavailable even while a cable is attached.

Canon TS3522 Not Connecting to WiFi
-----------------------------------

Check the Network Details
~~~~~~~~~~~~~~~~~~~~~~~~~

Confirm that you selected the correct WiFi name and entered its current password.

Passwords are case-sensitive. The WiFi password may differ from the password used to manage the router.

Check Wireless Compatibility
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Make sure the router offers a compatible 2.4 GHz network.

If you recently changed router settings, review those changes before repeatedly resetting the printer.

Improve the Signal
~~~~~~~~~~~~~~~~~~

Move the printer closer to the router during setup.

Walls, distance, and interference can make the connection unreliable.

Reconnect After a Router Change
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Run wireless setup again after replacing your router or changing the network name or password.

Once the printer reconnects, check whether the existing printer entry on your computer still works.

Canon TS3522 Showing Offline
----------------------------

Check that the printer is switched on, ready, and connected through the intended method.

Open the print queue and remove failed jobs. Resume printing if it is paused.

Confirm that your application is using the correct TS3522 entry.

If another device prints successfully, focus on the affected computer's queue, printer entry, and software.

Canon TS3522 Not Printing After Installation
-------------------------------------------

Check the printer display for an error and confirm that paper is loaded correctly.

Make sure the cartridges are installed properly and that their protective tape was removed as instructed.

Try printing a built-in test pattern using the model's maintenance procedure. If that works, investigate the computer connection and application next.

If only one file fails, try a short document from another application.

Scan with the Canon PIXMA TS3522
--------------------------------

The TS3522 includes a flatbed scanner. Place the document face down on the glass, aligned with its positioning mark, and close the lid gently.

Open a compatible scanning application and choose the correct scanner.

Select the document size, file format, and destination folder where available. Scan one page and check the saved file.

Printing and scanning may require different software components, so test both functions separately.

Frequently Asked Questions
--------------------------

What does IJ.start.Canon TS3522 setup involve?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

It involves preparing the printer, installing cartridges, loading paper, choosing a connection, and adding the device to your computer or phone.

Can I set up the TS3522 without a CD?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Yes. Depending on your device, installation can use a downloaded package or an available built-in printing method.

Can the TS3522 connect directly to a 5 GHz network?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The TS3522 uses 2.4 GHz WiFi. Your router needs to provide a compatible network for the printer.

Do I need WiFi for USB printing?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

No. A direct USB connection does not require WiFi, although obtaining missing installation software may require internet access.

Why does printing work but scanning does not?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Check the scanning application, scanner selection, and required scanning software. A basic printing installation may not include every scanning function.

Complete Your First Print and Scan
-----------------------------------

Print one short document and scan one page. Confirm that the printed output is correct and that the scanned file opens successfully.

Once both tasks work, your Canon PIXMA TS3522 is ready for everyday document printing and scanning.
